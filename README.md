# 🎮 MCFA Method 2.0 (Minecraft Full Access Activation Guide)

Comprehensive documentation outlining the Xbox Game Pass activation and Microsoft account linkage procedure to obtain permanent Minecraft Java & Bedrock licenses.

---

## 📋 The 7-Step Method

1. **Step 1 - Xbox Game Pass**: Obtain an active Xbox Game Pass subscription on your target Microsoft account.
2. **Step 2 - Bedrock Claim**: Install and launch **Minecraft: Bedrock Edition** via Microsoft Store.
3. **Step 3 - Cancel Subscription**: Cancel Game Pass recurring billing.
4. **Step 4 - Permanent Bedrock Retention**: The Bedrock edition license attaches permanently to your Microsoft account.
5. **Step 5 - Unified License Entitlement**: Under Mojang's unified entitlement policy, every Minecraft Bedrock owner automatically receives the complimentary Minecraft Java Edition license.
6. **Step 6 - Launcher Installation**: Download the official Minecraft Launcher from `minecraft.net`.
7. **Step 7 - Java Profile Setup**: Sign in with the same Microsoft email, create your in-game player profile name, and launch Java Edition.
